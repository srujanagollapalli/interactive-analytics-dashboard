# Interactive Analytics Dashboard

## Project Overview
An interactive data analytics dashboard built using Python, Pandas, Streamlit, and Plotly to analyze sales and profit performance across product categories and regions.

## Business Question
Which product categories and regions generate the highest sales and profit?

## Key Features
- Total Sales, Total Profit, Total Orders, and Average Discount KPIs
- Sales analysis by product category
- Profit analysis by region
- Monthly sales trend visualization
- Interactive filters for region, category, and order date
- Filtered data table and CSV download option

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- Jupyter Notebook

## How to Run Locally
1. Clone or download this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

4. Upload the `Sample - Superstore.csv` dataset when prompted, if it is not available locally.

## Dataset
The dashboard uses the Sample Superstore sales dataset. The CSV file is not included in this repository; upload your dataset through the dashboard.

## Project Goal
To identify sales trends, profitable product categories, and high-performing regions using interactive visualizations and business insights.
